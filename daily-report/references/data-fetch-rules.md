# 资料读取与使用规则

本文件定义 customer-chat-analyzer 生成日报前必须读取或纳入分析的资料范围，以及当日状态、日报、周报、月报、客户档案、企业信息、产品信息的使用边界。

## 一、启动输入

用户输入客户名称、客户昵称、客户编号或微信备注名。不要默认要求用户粘贴聊天记录原文。

示例：

```text
请生成客户【张总-西安养老项目】今天的客户日报。
```

## 二、必须纳入分析的资料

根据客户名称定位客户记录后，必须读取或纳入以下资料，并在日报正文前输出“本次分析资料范围”模块：

1. 当天聊天记录原文。
2. 当日状态。
3. 本周一至昨日已经生成的客户日报。
4. 本月当前周之前已经完成的周报。
5. 客户加微信月份至最近已完成月份的月报。
6. 客户档案。
7. 企业信息。
8. 产品信息。

若当前环境无法访问数据库、文档或连接器，必须要求用户提供资料，或在“本次分析资料范围”中标明“未提供/待补充”。不得编造缺失资料。

## 三、当日状态读取规则

当日状态是独立数据库资料，指客户信息数据库中该客户当天的状态记录，包括但不限于当前阶段、今日跟进状态、今日待办、负责人备注、系统状态字段、今日已完成动作和今日风险标记。

当日状态必须与当天聊天记录分开读取，并在“本次分析资料范围”模块中单独列示。若未提供，写“未提供/待补充”。

当日状态用于校准日报中的当前阶段、今日变化、未完成事项和下一步动作；不得替代当天聊天记录原文。

## 四、日报读取规则

日报读取范围为本周一至昨日已经生成的日报，默认周一为一周开始。

| 今天是 | 读取日报 |
| --- | --- |
| 周一 | 本周暂无历史日报 |
| 周二 | 周一日报 |
| 周三 | 周一、周二日报 |
| 周四 | 周一、周二、周三日报 |
| 周五 | 周一、周二、周三、周四日报 |
| 周六 | 周一至周五日报 |
| 周日 | 周一至周六日报 |

不得使用“前 3 日日报”作为默认规则。

## 五、周报读取规则

周报读取范围为本月当前周之前已经完成的周报。当前周尚未结束，不读取当前周周报。

| 当前处于本月第几周 | 抓取周报 |
| --- | --- |
| 第 1 周 | 本月暂无已完成周报 |
| 第 2 周 | 本月第 1 周周报 |
| 第 3 周 | 本月第 1、2 周周报 |
| 第 4 周 | 本月第 1、2、3 周周报 |
| 第 5 周 | 本月第 1、2、3、4 周周报 |

如果数据库已有明确周报标签，以数据库中的“本月第 N 周周报”标签为准。

## 六、月报读取规则

月报读取范围为客户加微信所在月份至最近已完成月报的月份。

示例：客户 4 月份加微信，当前已有 4 月、5 月、6 月月报，则读取 4 月、5 月、6 月月报。当前月份月报尚未生成时，不读取当前月份月报。

## 七、客户档案、企业信息、产品信息规则

- 客户档案：客户基础信息资料，用于补充客户身份、需求、预算、决策链、长期偏好、历史风险和禁忌话术；在本 Skill 中视为恒定基础信息，只作分析依据，不提示更新。
- 企业信息：用于保证公司介绍、资质、团队、服务能力等表述准确。
- 产品信息：用于保证产品名称、价格、服务内容、交付边界、案例、适用条件、不承诺事项等表述准确。

不得根据模型通用知识编造企业能力、产品价格、合同范围、退款规则、交付周期、客户案例或效果承诺。

## 八、资料冲突处理规则

资料之间不设置固定优先级。当天聊天记录、当日状态、本周日报、本月周报、客户月报、客户档案、企业信息、产品信息均需结合使用。

如资料内容存在冲突，以最近日期的资料为准；不得使用较早资料覆盖较新资料。

如两个资料日期相同但内容冲突，标注为“待核实”。若资料没有明确日期，使用数据库更新时间、文档版本号或生成时间作为日期依据；仍无法判断日期时，标注“日期不明，待核实”。

示例：

```text
客户档案显示客户预算充足，但今日聊天记录显示客户预算紧张。
处理方式：以今日聊天记录为准，日报中判断客户当前存在预算压力。
```

```text
5 月月报显示客户高意向，6 月月报显示客户持续观望。
处理方式：以 6 月月报为准。
```

## 九、本次分析资料范围模块格式

日报正文前必须输出：

```text
本次分析资料范围：
1. 当天聊天记录：已纳入分析 / 未提供
2. 当日状态：已纳入分析 / 未提供
3. 本周日报：周一、周二、周三…… / 未提供 / 本周暂无历史日报
4. 本月周报：第1周、第2周…… / 未提供 / 本月暂无已完成周报
5. 客户月报：4月、5月、6月…… / 未提供 / 暂无已完成月报
6. 客户档案：已纳入分析 / 未提供
7. 企业信息：已纳入分析 / 未提供
8. 产品信息：已纳入分析 / 未提供
```
