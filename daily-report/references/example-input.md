# 示例输入格式

用户通常只需要输入客户名称、客户昵称、客户编号或微信备注名，Skill 根据客户名称抓取该客户相关资料并生成日报。

```text
请生成客户【张总-西安养老项目】今天的客户日报。
```

```text
客户名称：李老师-职业培训合作
生成今日日报。
```

多客户输入时，可以写：

```text
请生成以下客户今天的日报：
1. 王总-养老项目
2. 李老师-职业培训
3. 赵总-短视频获客
```

Skill 应逐个客户抓取：当天聊天记录、当日状态、本周一至昨日日报、本月当前周之前已完成周报、客户加微信月份至最近已完成月份的月报、客户档案、企业信息、产品信息。

正式输出时，先输出“本次分析资料范围”模块，再输出原有两层日报。每个单客户日报必须包含“当日突出点”；如果抓取到本周日报、周报、月报或客户档案，还必须包含“变更记录”。如果只需要汇总，请明确说“只要汇总，不要逐客日报”。

如果当前环境无法访问数据库或文档，用户可以临时提供资料包，例如：

```text
客户名称：王总
日报日期：2026-07-03
当天聊天记录：……
当日状态：……
本周日报：周一……周二……
本月周报：第1周……第2周……
客户月报：4月……5月……6月……
客户档案：……
企业信息：……
产品信息：……
```

如果要求输出为 HTML、Word、PDF、Markdown 或其他可下载文件，Skill 默认每个客户生成一个独立日报文件，并单独生成所有客户当日总结日报文件；可额外生成目录页或压缩包。

所有客户当日总结日报默认只保留 4 个部分：今日总览、当日突出点、明日重点任务、团队话术/物料提醒。不要默认输出客户跟进清单和客户客户档案资料说明，除非用户明确要求。
