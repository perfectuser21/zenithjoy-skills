# Eval V2 二值断言评测表（唯一出处，v1.3）

自 v1.3 起评测判定为纯二值：每项只打 yes / no，不设"需人工复核"。拿不准一律判 no（从严）。修改评测规则只改本文件，SKILL.md §16 与 eval-v2-sop.md 不得另抄副本。

## 一、逐客户核心判断（原始得分层）

每个客户 4 个维度与 Golden Answer 比对，一致 = yes(1)，不一致 = no(0)，输出未覆盖该客户 = 全 no：

1. 阶段（A1-A4；Golden 写"A1 或证据不足"时两者任一算 yes）
2. 推进信号强度（无/弱/强三档）
3. 询价类型（未询价/模糊/调研型/购买型）
4. 主缺口与下一步动作方向

维度通过线：每个维度 yes 数 ≥ 85%（15 样本即 ≥13，30 样本即 ≥26）。

主观项操作化：第 8 项不判"自然度"，只判两条硬标准（无禁止项 + 对应主缺口）。

## 三、硬性失败项编号（与 SKILL.md §16.3 一致）

HF1 事实越界编造 · HF2 调研型询价强推付款 · HF3 高风险仍强推成交 · HF4 多客户无单客户日报 · HF5 历史覆盖今日 · HF6 编造客户身份或业务背景。

## 四、通过线（机械执行，无自由裁量）

- 不通过：任一 HF 命中；或任一核心项（#2/#3/#4/#6/#11）= no。
- 通过：无 HF，核心项全 yes，且 11 项中 yes ≥ 9。
- 部分通过：无 HF，核心项全 yes，但 yes ≤ 8。

不存在"需人工复核"结论。

## 五、多次运行规则

正式验收（30+ 样本）每个配置至少独立运行 3 次：11 项断言逐项取三次多数（≥2 次 yes 记 yes）；HF 任一次命中即计命中；核心四维报三次均值与最差值。快速冒烟与小型回归允许单次运行，但结论必须标注"单次运行，压线项未经重复验证"。
