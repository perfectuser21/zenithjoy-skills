# 业务规则

## 多公司与设备隔离

- `tenant_id` 表示公司/客户部署；`profile` 表示该租户下的一台具体手机。
- 每个租户独立登记 Node、设备 label、ADB serial、机型、传输方式和用途；不能跨租户复用 serial、默认 profile、账号池或线索表。
- 任务执行前必须形成唯一选择：`tenant_id → profile → Node → serial → model`。用户没有明确租户且当前环境存在多个租户时，先澄清，不按“工作机”、USB 顺序或在线状态猜测。
- 线索表、关键词表、运营账号矩阵、对标账号表和话术库也按租户绑定；设备恢复成功不代表可以使用另一家公司的业务数据或账号。

## 飞书数据源

- 唯一数据源是 `/root/clawd-media/config/social-media-tenants.json` 中当前 `tenant_id` 的 `feishu_account` 和 `tables`；不得把任何一家公司的 token/table_id 写成全局默认值。
- 关键词配置表：读取 `tables.keywords.app_token` 与 `tables.keywords.table_id`。
  - 主字段“抖音获客-关键词配置”作为关键词。
  - 使用字段：业务线、是否启用、目标人群、关键词层级、核心需求、搜索意图、意向信号、排除信号、扩词种子、采集目标、优先级、时间窗口天数、目标账号角色、测试状态、最近效果、备注。
  - 时间窗口为空时按 7 天。
- 线索表：读取 `tables.leads.app_token` 与 `tables.leads.table_id`。
  - 主字段“抖音获客-线索表”和“抖音昵称/主页链接”写同一个值。
  - 使用字段：业务线、目标人群、关键词层级、搜索意图、命中关键词、搜索账号、AI判断理由、状态、实际分发号、触达时间、话术内容。
- 运营账号矩阵：读取 `tables.account_pool.app_token` 与 `tables.account_pool.table_id`。
  - 采集模式也必须读取账号角色和当前登录状态；这不等于允许触达。
  - 使用字段：账号名称、抖音号、账号角色、是否当前登录、内容定位、目标人群、允许任务、每日上限、切换标识、最近核验时间、归属状态、登录优先级。
- 对标账号表：对标研究读取和写入 `tables.benchmark_accounts`；必须有清晰主页证据，不得编造账号。
- 话术库：话术实验或触达读取 `tables.script_library`。使用字段：话术ID、版本组、子版本、客服编号、客服电话、话术正文、CTA、目标流量占比、单批分配规则、启用状态、资质核验、数据证明、可发送状态。

飞书表读写必须使用当前租户的飞书机器人身份；调用本 Skill 的 `scripts/feishu-bitable.mjs` 时必须显式设置 `FEISHU_ACCOUNT_ID=<当前租户feishu_account>`。缺少任一绑定时停止，不得回退到 `main`。

## 线索分类

| 类型 | 判断特征 | 写入线索表 |
| --- | --- | --- |
| 强意向 | 明确表达想要、想学、求链接、询价或询问操作方法 | 是 |
| 弱意向 | 对真实性、可靠性、适用性表现出具体兴趣或犹豫 | 是 |
| 同行 | 从业者讨论经验或业务，不是在提出需求 | 否 |
| 无关 | 寒暄、表情、泛泛夸赞，没有实际需求 | 否 |
| 广告异常 | 营销引流、机器重复、主题无关广告 | 否 |

保留线索时，在“AI判断理由”中写入评论原文、分类和一句判断依据。评论时间超过关键词自己的时间窗口时跳过。

## 评论采集配额

- `batch_size=30` 是视频之间公平轮转的每轮大小，不是每个视频的总上限。
- 对同一搜索时间层，只采集该窗口内的平台可见评论；窗口外评论记录边界后跳过。
- 一轮先让每个合格视频最多取 30 条，再回到未取光的视频续取，直到每个视频都写明 `exhausted=true` 及取光依据。
- 数千/数万条评论必须分批落原始池和断点，不一次性放入模型上下文。

## 查重与边界

- 写入前必须按主页标识或“抖音昵称/主页链接”查重，同一人不能重复新增。
- 线索必须来自视频评论者，不得把视频作者误当作评论线索。
- 判断不明确时跳过，不为完成数量强行纳入。
- 不编造主页链接、评论、互动量、时间、价格、案例或效果。
- 定时采集模式禁止任何对外动作，包括点赞、关注、评论和私信。

## 后续触达规则

只有用户明确批准上线触达后才从运营账号矩阵选择分发号并执行。即便批准，也必须满足：

- 业务线匹配、账号状态正常、未超过每日上限；
- 单轮最多触达 1 人；
- 触达前再次查重；
- 话术库记录同时满足“启用状态=启用”“资质核验=已通过”“可发送状态=启用”；
- 话术不含未经确认的价格、案例、资质、统计数据、补贴/就业/取证结果或承诺，且同日不高度雷同；
- 中文输入链路已经完成实机验证；
- 触达后更新线索表和账号池计数；
- 遇风控立即停止并把账号状态改为“警告”。
