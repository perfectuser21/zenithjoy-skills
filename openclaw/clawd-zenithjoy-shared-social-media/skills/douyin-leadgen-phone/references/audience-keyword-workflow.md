# 目标人群与关键词工作流

## 核心顺序

不要先罗列产品属性或证书等级。先回答“要找谁”，再设计搜索词：

`业务目标 → 目标人群 → 核心需求 → 搜索意图 → 词层级 → 搜索与评论验证 → 效果反馈`

## 建立人群矩阵

每个租户自行定义目标人群。每类人群至少登记：

- 人群名称和业务线；
- 核心需求；
- 强意向、弱意向和排除信号；
- 搜索目标与转化目标；
- 优先级、状态和时间窗口。

人群必须互相可解释，但不要求完全互斥。同一线索可命中多个意图，最终在线索表中保留主要人群和判断依据。

## 从人群扩词

每类人群建立三层词：

| 层级 | 作用 | 常见结构 |
| --- | --- | --- |
| 宽词 | 扩大召回、发现新表达 | 品类、行业、职业、问题领域 |
| 精准词 | 捕获明确需求 | 品类 + 求职/考证/学习/价格/报名等动作 |
| 问题词 | 捕获自然语言意图 | 怎么、哪里、是否、值不值、适不适合、从哪开始 |

扩词来源包括搜索联想、热门视频标题、真实评论表达、对标账号主题和已转化线索原话。不得编造搜索量、互动量或转化数据。

## 运行与迭代

1. 每轮先轮换目标人群，再在人群内轮换启用关键词，避免某一人群长期占满采集配额。
2. 宽词用于发现，精准词和问题词用于验证；不能只跑非常细的长尾词。
3. 评论筛选必须结合人群的意向信号和排除信号，由语义判断完成，不用单一关键词命中代替。
4. 回写关键词的搜索结果数、有效评论数、有效线索数、重复数和后续转化；没有真实数据时写“待积累”，不打假分数。
5. 定期扩充高质量表达，暂停长期无结果或大量无关的词；保留历史记录便于复盘。
6. 新行业复用同一流程，只更换租户的人群、词库、账号和话术数据。金融证券、语音终端、职业教育等业务不得共享具体关键词或合规文案。
7. 产品等级、证书等级或其他行业分类表不是本 Skill 的标准组件，不跨租户复用，也不作为关键词轮换前置条件。

## 关键词表最小字段

`关键词、是否启用、业务线、目标人群、关键词层级、核心需求、搜索意图、意向信号、排除信号、扩词种子、采集目标、优先级、时间窗口、目标账号角色、测试状态、搜索视频数、查看评论数、有效线索数、重复线索数、转化数、最后测试时间、最近效果、备注`。
