# 账号路由

## 角色由租户配置，不由 Skill 写死

- 一台手机可以保存多个抖音账号；`phone_profile` 只选设备，不能代替账号选择。
- 每个租户在配置和“运营账号矩阵”中登记 `账号名称、抖音号、账号角色、允许任务、切换标识、账号状态、每日上限、登录优先级`。
- 共享 Skill 只理解能力角色，不保存任何公司的昵称、电话或业务文案。

推荐角色：

| 能力角色 | 允许任务 | 默认禁止 |
| --- | --- | --- |
| 主搜索号 / search-primary | 目标人群研究、关键词搜索、热点内容、评论采集、对标研究 | 私信、评论、关注、点赞 |
| 分发号 / distribution-subaccount | 经授权的话术分发、回复跟进、转化记录 | 未授权触达、自动扩词、跨租户搜索 |

一个租户可以有一个或多个搜索号、分发号。账号昵称不是角色；“主号/小号”也不是设备身份。客服、话术版本和抖音账号是三个独立维度，必须分别记录。

## 路由规则

1. 搜索、扩词、评论采集和对标研究选择状态正常的搜索号。
2. 触达任务只选择状态正常、未超过每日上限的分发号，并要求用户明确批准本轮触达。
3. 多个同角色账号按稳定轮换和剩余容量选择，不按账号列表位置或当前登录状态偷懒选取。
4. 账号角色与当前选中账号不一致时，只有租户任务策略或用户指令已授权切换才执行；切换后必须复核选中标记。
5. 出现密码、验证码、登录确认、实名、安全设置或风控时立即停止。

## 切换 SOP

1. 预检租户、profile、Node、serial、model、通话和屏幕状态。
2. 读取“运营账号矩阵”，确定本轮所需能力角色和唯一目标账号。
3. 进入“我”页和账号切换列表，截图核对全部账号及当前选中项。
4. 精确点击租户登记的切换标识；不得使用坐标猜测未知账号。
5. 切换后重新进入“我”页或切换列表确认选中标记，并更新当前登录状态和核验时间。
6. 账号 ID 未核验时只能记录“昵称已选择、ID待核验”，不得补造抖音号。

## 数据表职责

- `运营账号矩阵`：保存设备上的真实账号、能力角色、当前登录、每日上限和允许任务。
- `关键词配置`：保存目标人群、搜索意图、宽词/精准词/问题词、测试状态和效果反馈。
- `对标账号`：保存真实对标账号和内容结构；没有清晰主页证据时不新增。
- `抖音线索`：保存评论者线索及搜索号、分发号、话术、客服、回复和转化，不把视频作者当成评论线索。

对标账号采集默认只读。禁止关注、点赞、评论、私信或复制对方受版权保护的长文本。
