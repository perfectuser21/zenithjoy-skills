# Eval Run Result V2.0

## 本次版本

Eval V2.0 客观评测版。相对旧版 Eval，本次新增：

1. `references/eval-v2-sop.md`：严格客观 Eval 流程，包含 baseline 对照、Golden Answer、盲评、双人评分和报告模板。
2. `references/eval-v2-scorecard.md`：100 分权重制评分卡，包含逐项扣分规则和硬性失败项。
3. `references/eval-v2-golden-answer-template.md`：标准答案模板，用于提前固定每个测试样本的正确判断。
4. `SKILL.md` 已更新 Eval 选择规则：快速演示用旧样例；严格验收必须优先使用 Eval V2.0。
5. 新增限制：无法独立运行 baseline 时必须说明，不得虚构 baseline 分数、盲评结果或双人评分结果。

## 本次 Eval 结论

通过，但仅代表 6 客户样例的快速冒烟回归通过，不代表正式上线验收。

本次新版 Eval 的主要改进不是把分数写得更高，而是把评测方式变得更可复查：

1. 旧版偏“检查清单”，V2.0 改为“Golden Answer + 100 分评分卡 + 硬性失败项”。
2. 旧版容易主观给满分，V2.0 细化了每项扣分规则。
3. 旧版没有 baseline 透明限制，V2.0 要求无法独立运行 baseline 时必须说明，不得虚构。
4. 旧版样本较少，V2.0 明确正式验收建议 30 个以上样本。
5. 旧版强调 Skill 是否符合规则，V2.0 同时要求看 Skill 是否优于 baseline。

## 下一轮建议

1. 建立 30 个正式测试样本，覆盖基础阶段、询价分级、高风险、连续跟进、多人决策、同行比较和文件输出。
2. 为每个样本提前写 Golden Answer。
3. 在独立会话中分别运行 Baseline 0、Baseline 1 和 Skill Run。
4. 采用盲评或双人评分，输出正式 V2.0 Eval 报告。
