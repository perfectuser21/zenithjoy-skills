# 能力满分评分卡

本文件用于对客户聊天记录分析 Skill 做严格 eval、验收或与“无 Skill 分析”做对比。评分重点不是文字长短，而是判断是否稳定、证据是否充分、动作是否可执行、输出是否符合两层日报结构、单客户是否有当日突出点和变更记录、文件输出是否符合单客户单文件原则、汇总日报是否足够压缩可扫读。

## 评分方法

- 每项满分 10 分。
- 使用 Skill 的目标是 10/10；只要输出满足“满分标准”，即可给满分。
- 如果用户没有提供真实产品细节，不能因缺少产品细节直接扣分；只要输出明确标注“待补充/未体现”，并不编造细节，即可满足业务适配项满分。
- 不用 Skill 的评分按实际输出质量判断，常见扣分来自阶段混淆、弱信号强收口、高风险客户不刹车、动作空泛、模板缺失、只给汇总不沉淀单客户日报、单客户日报缺少当日突出点或变更记录、文件输出把多个客户合并到一个文件、汇总日报默认输出客户跟进清单或长期档案表导致过长。

## 逐项能力评分标准

| 能力项 | 满分标准 | 常见扣分点 |
| --- | --- | --- |
| A1-A4 阶段稳定性 | 阶段只按客户已完成动作判断；证据不足时写置信度与缺失证据 | 按意向强弱升级阶段；把愿意聊、愿意试、已购买混淆 |
| 推进信号识别 | 先判断推进信号，再决定收口/补缺口；写出信号原话和强弱 | 客户已问资料/付款却继续解释；或无信号强推 |
| 询价分级 | 所有问价都区分购买型、调研型、模糊询价 | 把所有问价都当高意向，或完全不判断询价类型 |
| 四感缺口判断 | 输出主缺口、最大阻力和沟通重点；详细版再写次缺口、默认权重、临时调整原因 | 只写“有顾虑/要信任/要解释”，没有四感落点 |
| 高风险客户识别 | 明确识别保证结果、拒绝配合、拒绝边界等风险，并允许暂不推进 | 对高风险客户继续劝单、承诺效果或降价成交 |
| 下一步动作可执行性 | 下一步动作包含对象、动作、时间/条件、边界或资料要求 | 只写“继续跟进、发资料、加强沟通” |
| 单客户当日突出点 | 每个单客户日报都独立输出“当日突出点”，并覆盖机会、风险、变化、卡点或动作中的至少一类 | 只在汇总日报写突出点；单客户日报缺该字段；突出点泛泛而谈或无记录依据 |
| 连续跟进与变更记录 | 有历史材料时沿用上一有效客户状态，只核验未完成事项和今日变化；单客户日报输出变更项、变更前、变更后、变更原因、证据和动作影响 | 把历史日报、周报、月报和档案重新分析一遍；重复判定旧结论；没有说明为什么变化；无关键变化时不写沿用判断 |
| 汇总日报简洁度 | 所有客户当日总结日报默认只保留 4 个部分：今日总览、当日突出点、明日重点任务、团队话术/物料提醒；不默认输出客户跟进清单和客户长期档案更新表 | 汇总日报默认输出客户跟进清单、长期档案更新表或其他明细表；把单客户日报内容重复搬到汇总日报；管理者无法快速扫读 |
| 两层日报完整度 | 多客户默认先输出每个客户的单客户日报，再输出所有客户当日总结日报；文件输出场景默认单客户单文件、汇总单文件 | 只给总览和客户清单；只展开重点客户；普通客户没有单客户日报；HTML/Word/PDF 把多个单客户日报合并成一个文件 |
| 团队复盘价值 | 汇总日报输出高意向/可收口客户、突出机会、突出风险、突出变化、主要卡点、话术问题和按任务主题聚合的明日重点 | 只做单点建议；明日重点逐客重复单客户下一步动作；无法用于团队沉淀或统计 |
| 话术稳定性 | 话术按“回应顾虑→补主缺口→低阻力下一步”，克制不夸大 | 解释过多、催单过猛、攻击同行、承诺保结果 |
| 真实业务适配潜力 | 真实产品信息有则优先使用；没有则标“待补充/未体现”，不编造 | 因缺资料乱编价格/案例/条款，或不提示需补充什么 |
