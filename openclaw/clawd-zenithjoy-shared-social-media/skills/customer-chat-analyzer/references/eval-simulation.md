# 模拟 Eval：客户聊天记录分析 Skill

本文件用于评估该 Skill 是否能稳定执行 A1-A4 阶段判断、四感缺口判断、推进信号识别、复杂信号抗干扰、下一步动作设计、建议回复话术生成，以及“两层日报”“单客户单文件”和“4 部分简洁汇总日报”输出结构。

## Eval 使用方法

1. 把“样例输入”作为用户提供的聊天记录。
2. 按 `SKILL.md` 和 `references/output-template.md` 输出分析。
3. 检查输出是否先生成每个客户的单客户当日日报，再基于每个单客户日报生成所有客户当日总结日报。
4. 检查每个单客户当日日报是否都有“当日突出点”；若输入包含历史日报、周报、月报或客户档案，还要检查是否有“变更记录”。
5. 如果用户要求 HTML、Word、PDF、Markdown 或其他可下载文件，检查是否按“单客户单文件 + 汇总单文件”输出。
6. 检查所有客户总结日报是否默认只保留 4 个部分：今日总览、当日突出点、明日重点任务、团队话术/物料提醒。
7. 检查所有客户总结日报是否没有默认输出客户跟进清单和客户长期档案更新表。
8. 对照“期望核心判断”和“验收清单”检查结果。
9. 不要求逐字一致，但阶段、推进信号、主缺口、跟进优先级、下一步动作方向、当日突出点、变更记录、两层日报结构、文件拆分方式和汇总日报简洁度必须一致。

# 两层日报结构验收

合格输出必须满足：

1. 先输出“第一部分：单客户当日日报”。
2. 每个客户都必须有一份单客户日报，不得只展开重点客户。
3. 每份单客户日报必须包含：当前阶段、推进信号、询价类型、阶段判断依据、当日突出点、变更记录、主缺口/最大阻力、适配风险、下一步动作、建议回复、内部跟进记录、长期档案提醒。
4. “当日突出点”必须在每个单客户日报中出现，不得只出现在所有客户总结日报里。
5. 再输出“第二部分：所有客户当日总结日报”。
6. 总结日报必须基于前面的单客户日报汇总，不能出现前文没有依据的新判断。
7. 总结日报默认只包含 4 个部分：今日总览、当日突出点、明日重点任务、团队话术/物料提醒。
8. 总结日报默认不得输出客户跟进清单和客户长期档案更新表，避免重复单客户日报。
9. 明日重点任务必须按团队任务主题聚合，不能把单客户日报中的逐客下一步动作换个说法重复一遍。
10. 客户很多时可以压缩单客户日报文字，但不能取消单客户日报。

# 文件输出结构验收

当用户要求把日报输出为 HTML、Word、PDF、Markdown 或其他可下载文件时，合格输出必须满足：

1. 每个客户各自生成一个独立日报文件。
2. 多个客户的单客户日报不得合并在同一个 HTML 页面或同一个 Word/PDF/Markdown 文件中，除非用户明确要求合并。
3. 所有客户当日总结日报必须单独生成一个汇总文件。
4. 可额外生成目录页或 index 文件，但目录页不得替代单客户日报。
5. 每个单客户文件都必须包含“当日突出点”。
6. 文件名应能看出客户名和日报类型，例如 `01_王总_单客户当日日报.html`。

# 通用质量检查

- [ ] 所有客户均单独分析，不合并。
- [ ] 阶段按已完成动作判断；证据不足时说明置信度。
- [ ] 每个客户都先判断推进信号，再决定收口或补缺口。
- [ ] 问价必须区分购买型、调研型和模糊询价。
- [ ] 客户有推进信号时，建议动作聚焦收口，不继续补理论。
- [ ] 四感占比用于判断沟通重点，而不是话术篇幅比例。
- [ ] 每个客户给出一个明确、低阻力、可执行的下一步动作。
- [ ] 每个单客户日报都包含“当日突出点”。
- [ ] 有历史材料时，每个单客户日报都包含“变更记录”，且只记录今日相对上一有效状态的变化。
- [ ] 汇总日报中的当日突出点来自单客户日报，不替代单客户日报。
- [ ] 文件输出场景默认按“单客户单文件 + 汇总单文件”交付。
- [ ] 汇总日报默认只保留 4 个部分：今日总览、当日突出点、明日重点任务、团队话术/物料提醒。
- [ ] 汇总日报默认没有输出客户跟进清单和客户长期档案更新表。
- [ ] 明日重点任务按团队任务主题聚合，没有重复单客户日报中的逐客下一步动作。
- [ ] 建议回复话术自然、克制、不夸大承诺、不强推升级。
- [ ] 缺失信息标为“未体现”或“暂无法判断”，不编造。
- [ ] 高风险客户必须允许“暂不推进/暂不承接”。
- [ ] 多客户输出必须是“两层日报”，不能只输出总结性日报。

## 本次模拟 Eval 结论

本 eval 覆盖基础 A1-A4 阶段边界、调研型询价、高风险客户、单客户当日突出点、两层日报结构、文件拆分结构和 4 部分简洁汇总日报。通过标准不是文字长短，而是是否先沉淀每个客户当日日报，再做简洁可扫读的所有客户总结日报，同时保持阶段、推进信号、四感缺口、风险、当日突出点、变更记录、下一步动作、文件输出结构和汇总日报简洁度稳定。
