# 示例输入格式

用户可以每天直接粘贴客户聊天记录。建议每个客户单独一段：

```text
客户1：张总
客户：你们这个是做什么的？多少钱？
销售：我们主要帮企业做短视频获客流程优化……
客户：我先了解一下，怕后面很麻烦。

客户2：李老师
客户：我已经买了低价课，今天看完了。下一步怎么做？
销售：可以先看你的账号数据……
客户：那你发我需要准备的资料吧。
```

多客户输入时，Skill 默认先输出每个客户的单客户当日日报，再根据这些单客户日报生成所有客户当日总结日报。每个单客户日报必须包含“当日突出点”；如果同时提供历史日报、周报、月报或客户档案，还必须包含“变更记录”。如果只需要汇总，请明确说“只要汇总，不要逐客日报”。

如果要求输出为 HTML、Word、PDF、Markdown 或其他可下载文件，Skill 默认每个客户生成一个独立日报文件，并单独生成所有客户当日总结日报文件；可额外生成目录页或压缩包。


所有客户当日总结日报默认只保留 4 个部分：今日总览、当日突出点、明日重点任务、团队话术/物料提醒。不要默认输出客户跟进清单和客户长期档案更新表，除非用户明确要求。
