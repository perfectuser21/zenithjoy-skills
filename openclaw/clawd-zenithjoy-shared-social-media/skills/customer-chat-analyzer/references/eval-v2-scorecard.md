# Eval V2.0 客观评分卡

本文件用于对 customer-chat-analyzer 的输出进行更全面、公正、客观的评测。V2.0 不再只看输出是否覆盖字段，而是同时检查标准答案一致性、证据充分性、扣分尺度、baseline 对比、硬性失败项和复测稳定性。

## 一、评分原则

1. 使用同一份测试输入评分 Baseline 0、Baseline 1 和 Skill Run。
2. 评分前先准备 Golden Answer，不得边看输出边临时修改标准答案。
3. 优先按客户原话和已完成动作评分，不按模型表达是否好听评分。
4. 不以字数长短评分；输出更长但判断更差不得加分。
5. 缺少真实产品信息时，不因“未提供产品细节”扣分；但编造价格、案例、退款、合同、交付周期必须扣分。
6. 有历史材料时，必须检查“上一有效状态 + 今日新证据 + 今日变化”的连续跟进逻辑。

## 三、逐项评分标准

### 1. 输入拆分与证据使用，8 分

| 表现 | 得分 |
| --- | ---: |
| 正确识别所有客户，逐个分析，并引用关键证据 | 8 |
| 客户拆分基本正确，但个别客户证据引用不足 | 6 |
| 有客户被合并、遗漏，或证据引用较少 | 4 |
| 多客户混在一起分析，无法对应客户 | 2 |
| 严重遗漏客户或编造客户身份 | 0 |

扣分规则：每遗漏 1 个客户扣 2 分；每编造 1 个客户身份扣 3 分；完全没有原话或事实证据时最多 4 分。

### 2. A1-A4 阶段判断，14 分

| 表现 | 得分 |
| --- | ---: |
| 所有客户阶段判断正确，且阶段依据来自已完成动作 | 14 |
| 1 个客户阶段轻微偏差，但有证据意识 | 11-13 |
| 2 个客户阶段错误，或把意向强弱当阶段 | 7-10 |
| 多个客户阶段混乱，频繁把愿意聊、愿意试、已购买混淆 | 3-6 |
| 阶段体系基本失效 | 0-2 |

扣分规则：把 A1 误判为 A2/A3，每次扣 3 分；把 A2 误判为 A3，每次扣 2 分；把 A3 误判为 A4，每次扣 3 分；证据不足却高置信度判断，每次扣 2 分；明确已签约付款却未识别 A4，每次扣 3 分。

### 3. 推进信号识别，10 分

| 表现 | 得分 |
| --- | ---: |
| 能区分无推进、弱推进、强推进，并写出依据和是否收口 | 10 |
| 大体正确，但个别信号强弱判断偏差 | 7-9 |
| 只判断有没有意向，不区分强弱 | 4-6 |
| 把弱信号普遍当强信号，或强信号没有收口 | 1-3 |
| 完全没有推进信号判断 | 0 |

扣分规则：强推进信号没有收口，每次扣 2 分；弱推进信号被强行收口，每次扣 2 分；无推进信号却催付款，每次扣 3 分。

### 4. 询价分级，8 分

| 表现 | 得分 |
| --- | ---: |
| 所有问价都能准确区分购买型、调研型、模糊询价 | 8 |
| 大部分正确，1 处轻微偏差 | 6-7 |
| 能识别问价，但分级不稳定 | 3-5 |
| 把所有问价都当高意向 | 1-2 |
| 完全没有询价类型判断 | 0 |

扣分规则：调研型询价误判为购买型，扣 3 分；模糊询价直接判断为强推进，扣 2 分；购买型询价没有收口，扣 2 分。

### 5. 四感缺口判断，10 分

| 表现 | 得分 |
| --- | ---: |
| 主缺口准确，次缺口合理，能解释为什么 | 10 |
| 主缺口基本准确，但解释略泛 | 7-9 |
| 能提到四感，但主缺口不稳定 | 4-6 |
| 只写“客户有顾虑/需要信任”，没有落到四感 | 1-3 |
| 完全没有四感判断 | 0 |

扣分规则：主缺口错判，每次扣 2 分；已有强推进信号还继续大段补四感，扣 2 分；把四感占比写成话术篇幅比例，扣 2 分。

### 6. 高风险与不适配识别，10 分

| 表现 | 得分 |
| --- | ---: |
| 准确识别高风险客户，并允许暂不推进/暂不承接 | 10 |
| 识别风险，但边界话术不够清楚 | 7-9 |
| 风险识别不稳定，仍有轻微强推倾向 | 4-6 |
| 明显高风险客户仍继续劝单 | 1-3 |
| 承诺保效果、保成交、保回本 | 0 |

硬扣分规则：客户要求保证成交且拒绝配合，未判高风险扣 5 分；对高风险客户继续承诺效果扣 10 分并触发硬性失败项。

### 7. 下一步动作可执行性，12 分

| 表现 | 得分 |
| --- | ---: |
| 每个客户动作都有对象、动作、时间/条件、资料/边界 | 12 |
| 动作基本可执行，但少量客户缺时间或边界 | 9-11 |
| 动作方向正确，但执行颗粒度不足 | 5-8 |
| 多数动作空泛，例如“继续跟进、加强沟通” | 1-4 |
| 没有下一步动作 | 0 |

合格动作必须包含：谁来做、做什么、什么时候做或在什么条件下做、交付什么/确认什么/边界是什么。

### 8. 建议回复话术，8 分

| 表现 | 得分 |
| --- | ---: |
| 话术自然克制，回应顾虑，补主缺口，给低阻力下一步 | 8 |
| 话术方向正确，但略长或略模板化 | 6-7 |
| 话术能用，但没有聚焦主顾虑 | 3-5 |
| 话术催单、压迫、承诺过度 | 1-2 |
| 话术不可直接发送 | 0 |

扣分规则：没有明确下一步扣 2 分；攻击同行扣 2 分；承诺保效果扣 8 分并触发硬性失败项。

### 9. 连续跟进与变更记录，8 分

适用于含历史日报、周报、月报或客户档案的样本。

| 表现 | 得分 |
| --- | ---: |
| 能提取上一有效状态，只判断今日变化，并输出变更记录 | 8 |
| 基本能沿用历史状态，但变更原因不够清楚 | 6-7 |
| 有变更记录，但重复分析历史内容 | 3-5 |
| 有历史材料却没有变更记录 | 1-2 |
| 用旧信息覆盖今日新信号 | 0 |

扣分规则：没有历史材料时不因缺少变更记录扣分；有历史材料却没有“变更前/变更后/变更原因”扣 3 分；把历史推进信号直接当作今日强推进扣 3 分；今日出现降级信号却沿用旧高意向扣 4 分。

### 10. 两层日报与汇总结构，8 分

| 表现 | 得分 |
| --- | ---: |
| 多客户先单客户日报，再所有客户总结日报；汇总只保留 4 部分 | 8 |
| 两层结构存在，但汇总略重复 | 6-7 |
| 有单客户分析，但汇总结构混乱 | 3-5 |
| 只输出汇总，不输出单客户日报 | 1-2 |
| 多客户完全混合分析 | 0 |

扣分规则：每缺 1 个客户的单客户日报扣 2 分；单客户日报缺“当日突出点”每个客户扣 1 分；汇总日报复制单客户日报内容过多扣 2 分；汇总日报默认输出过多附加表扣 1-2 分。

### 11. 真实业务适配与不编造，4 分

| 表现 | 得分 |
| --- | ---: |
| 真实信息有则使用，没有则标“待补充/未体现”，不编造 | 4 |
| 基本不编造，但待补充项提示不足 | 3 |
| 出现轻微未经证实的业务假设 | 1-2 |
| 编造价格、案例、合同、退款、交付周期 | 0 |

## 四、硬性失败项

出现任意一项，本次 Eval 直接判为“不通过”，即使总分较高也不能通过。

1. 对高风险客户承诺保成交、保回本、保效果。
2. 明确调研型询价，却强推付款或合同。
3. 多客户场景完全没有单客户日报。
4. 明确已签约付款的客户，却没有识别为 A4 或交付启动阶段。
5. 有历史材料，但用旧信息覆盖今日新证据。
6. 编造产品价格、退款规则、客户案例、合同条款或交付周期。
7. 建议销售使用明显欺骗性话术。
8. 文件输出场景默认把多个客户日报合并成一个文件，且没有清晰分隔。
9. 输出严重偏离客户聊天记录，无法追溯证据。
10. 对暂不适配客户仍要求销售强行成交。

## 五、通过标准

### 普通通过

同时满足：总分不低于 85 分；没有硬性失败项；A1-A4 阶段判断不低于 11/14；高风险识别不低于 8/10；下一步动作可执行性不低于 9/12；两层日报结构不低于 6/8。

### 优秀通过

同时满足：总分不低于 92 分；没有硬性失败项；Skill Run 比 Baseline 1 至少高 8 分；高风险识别、询价分级、阶段判断均无严重错误；多客户汇总能直接用于团队复盘。

### 不通过

任意满足：总分低于 85 分；出现硬性失败项；高风险识别低于 6/10；阶段判断低于 9/14；下一步动作大量空泛；Skill Run 不明显优于 Baseline 1。
