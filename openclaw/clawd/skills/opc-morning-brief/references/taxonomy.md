# OPC Operating Taxonomy

## Hierarchy

1. Evidence / Work Item: smallest verified unit such as a task, incident, commit, deployment, content item, lead, meeting commitment, or metric observation.
2. Capability: a stable business ability measured through evidence lines.
3. Value Stream: a flow that turns an input into customer or company value.
4. Portfolio: a collection of value streams with one strategic outcome.
5. Company: the final operating conclusion across Portfolios.

## Portfolio: AI Deployment and FDE

### Value Stream: Lead to Solution

- `FDE-01` Opportunity and lead qualification
- `FDE-02` Customer discovery and workflow definition
- `FDE-03` Solution architecture and commercial scope

### Value Stream: Solution to Production

- `FDE-04` Data and system integration
- `FDE-05` Model, prompt, tool, and evaluation quality
- `FDE-06` Deployment, security, observability, and acceptance

### Value Stream: Delivery to Reuse

- `FDE-07` Documentation, training, and handover
- `FDE-08` Reusable connectors, skills, templates, and productization

## Portfolio: Media and Growth

### Value Stream: Insight to Content

- `MED-01` Audience and topic intelligence
- `MED-02` Content backlog and editorial planning
- `MED-03` Script and asset production

### Value Stream: Content to Distribution

- `MED-04` Publishing readiness and approvals
- `MED-05` Multi-platform distribution and account health
- `MED-06` Content performance and learning

### Value Stream: Attention to Lead

- `MED-07` Lead capture and qualification
- `MED-08` Outreach, response, and conversion follow-up

## Portfolio: Engineering and Platform

### Value Stream: Idea to Code

- `ENG-01` Repository inventory and ownership
- `ENG-02` Requirements, design, and implementation flow
- `ENG-03` Tests, review, and code quality

### Value Stream: Code to Production

- `ENG-04` CI, packaging, release, and deployment readiness
- `ENG-05` Production change and rollback readiness

### Value Stream: Operate to Improve

- `OPS-01` Server, container, node, and Gateway health
- `OPS-02` Monitoring, incidents, capacity, and cost
- `OPS-03` Backup, recovery, security, and credential hygiene

## Portfolio: Company Operations

### Value Stream: Goal to Work

- `ORG-01` Goals, priorities, and task decomposition
- `ORG-02` Ownership, deadlines, and acceptance criteria

### Value Stream: Work to Accountability

- `ORG-03` Progress, blockers, overdue work, and workload
- `ORG-04` Meetings, commitments, and follow-up

### Value Stream: Decision to Learning

- `ORG-05` SOP, knowledge, and reusable organizational memory
- `ORG-06` Decisions required from the owner
