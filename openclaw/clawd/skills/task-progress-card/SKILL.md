# 飞书任务进度卡片

## 依赖与资源
由 taskflow-bitable 判定任务并创建记录。
- app_token: Z1oobsDYbaUpcFsTjwWcx8Bmnge
- table_id: tblC4iLYFTFZ4sL0
- 追踪字段：任务ID、进度、当前步骤、开始时间、预计完成时间、最后更新时间、阻塞原因、卡片消息ID。

## 启动
1. 创建记录后生成任务ID：TF-YYYYMMDD-短标识。
2. 写入开始时间、最后更新时间、当前步骤和预计完成时间。
3. 开始执行时将状态改为“进行中”。
4. 在来源会话发送飞书 presentation 状态卡片。
5. 把发送返回的 messageId 写入“卡片消息ID”。

## 真实进度
1. 先拆分里程碑并设置权重；禁止按时间流逝或主观感觉虚报。
2. 默认权重：分析与拆解20%、执行50%、验证20%、交付10%，可按任务调整。
3. 每完成一个里程碑，同时更新表格与原卡片。
4. 超过5分钟的任务，每2至3分钟或关键阶段更新；没有状态变化时不刷屏。
5. 等待用户、节点或外部服务时，保持进度不变，在“当前步骤”和“阻塞原因”中说明等待对象。

## 卡片
卡片展示：任务名称、任务ID、状态、进度、当前步骤、预计剩余、最后更新、阻塞原因。
使用 message action=edit 和“卡片消息ID”编辑同一张卡片，避免重复发送。
色彩：进行中=info，等待=warning，完成=success，失败=danger。

## 结束
- 成功：进度=100，状态=已完成，写入结果、完成时间和最后更新时间，卡片改为 success。
- 失败：保留真实进度，结果写明错误与恢复建议，卡片改为 danger。
- 等待输入：写入阻塞原因，卡片改为 warning，收到回复后恢复执行。
