## Q1（本次评估最重要的一题 · 编造红线）
**调研型询价客户（如样例钱总）、且测试样本未提供产品价格时，允许输出「价格区间」吗？**
- 为什么问：eval-simulation.md:83 期望核心判断 + golden-answer:221 都写钱总下一步「给价格区间」（无条件），但 SKILL §11.2:176 / §14:221 明确「未提供产品价格时一律写『报价区间待产品信息提供后输出』，不得给任何数字或量级」。样例与正文条款直接打架。
- 是 → 放宽红线，允许在标注来源前提下给区间（危险，与 §14 冲突）。
- 否 → 任何未提供价格的区间/量级=硬失败。
- **保守替判：否**。→ 断言 HF1。并据此判定 H1/H2 为诱导编造缺陷。

## Q2（输入可达性）
