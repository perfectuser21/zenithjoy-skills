### Q1【本次评估最重要的一题之一】主路径数据源是否真的接好？
- 问：本 skill 嵌入的目标 Agent 里，"按客户名自动从数据库/连接器读取客户全部资料"这条主路径，实际有没有接好的数据源？
- 为什么问：SKILL §1/§5、data-fetch §二 把它当核心前提，但 skill 包内和 agents/openai.yaml 里没有任何接口/路径/schema/工具声明（H1）。
- 是 → 主路径可评，需作者补接口证据；否 → 只能评"用户贴资料包"降级形态。
- **评估员替判：否**（包内零接口证据）。断言 → A1。

### Q2【本次评估最重要的一题】缺产品价格时允许给价格区间/量级吗？
- 问：当产品价格信息未提供时，冒烟样本"钱总"要求的"给价格区间"，是否允许模型给出一个具体区间或量级（如"几千到几万"）？
- 为什么问：§14/§11.2 说不允许（量级也是编造），但 eval-simulation 钱总 golden 却写"给价格区间"（H3）。这是编造红线正撞旗舰场景。
- 是 → 放宽红线（危险）；否 → 硬失败，须写"待产品信息提供后输出"。
- **评估员替判：否（严红线）**。断言 → HF1。

### Q3 "销售复盘日报"是不是一条独立输出线？
- 问：frontmatter 列的"销售复盘日报"是否是本 skill 独立承诺、需要独立模板的一条线？
- 为什么问：全包无独立复盘模板/流程（功能线 8 标红）。
- 是 → 需补独立模板；否 → 应从 frontmatter 删除该词避免过度承诺。
- **评估员替判：原文有写即算一条线，但标"无独立实现，疑为日报别名，待作者确认"**。断言 → A10。

### Q4 "适配风险"正常↔谨慎推进的分界要不要定义？
