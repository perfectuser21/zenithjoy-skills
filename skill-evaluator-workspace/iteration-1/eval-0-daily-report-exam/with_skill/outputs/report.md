## 二、梳理向导记录

8 题，无头模式：作者 0 答 / 评估员保守替判 8（全部待作者复核）。替判项：
- Q1 主路径数据源 → 替判"否/未接好"
- Q2【最重要】缺价格能否给区间 → 替判"否/严红线"
- Q3 复盘日报是否独立线 → 替判"原文有写即立线，但标未实现待确认"
- Q4 适配风险档位分界 → 替判"未定义"
- Q5 Eval 核心项集合 → 替判"未定义，裁决当前不可机械执行"
- Q6 缺料句式库 / Q7 版本统一 / Q8 长输出护栏 → 替判"是/建议补"

→ 生成断言合同 17 条（HF 3 · 核心 8 · 参考 6，详见 contract-assertions.md）。其中 A9/A10/A11/A13 静态即 FAIL（定义缺失/未实现/版本不一致）。

## 四、缺陷清单（H → M → L）

**H1 · 数据源接口全包缺失**（输入无来源）：1-5 线主路径核心前提"按客户名读库"，包内含 openai.yaml 零接口/schema/工具声明 → 主路径不可执行。降级路径（用户贴资料包）已定义故非死路。位置：SKILL §1/§5/§7、data-fetch §二/§五、agents/openai.yaml。修复：包内声明宿主数据源接口契约，或显式声明"仅消费用户贴入资料包"。**建议回 skill-creator 迭代。**

**H2 · Eval 最终裁决不可机械执行**（标准模糊）：通过标准写"核心项全部通过""大部分通过"，但 11 项断言表从未标注核心项、"大部分"无阈值。位置：eval-v2-scorecard §五/§七、eval-v2-sop §十一。修复：显式标核心/参考分级 + 给数值阈值。**建议回 skill-creator 迭代。**

**H3 · 冒烟旗舰样本 golden 与反编造铁律冲突**（内部矛盾）：eval-simulation 钱总（未提供产品价格）期望"给价格区间"，与 §14/§11.2 及 v2 golden"不得给量级"三处冲突，照跑触发关键失败项"事实越界编造"。位置：eval-simulation 期望表 vs §11.2/§14 vs golden §六。修复：钱总期望改为"有产品信息才给区间，否则写待补充"。**建议回 skill-creator 迭代。**

**M1 · eval/两层日报规则多文件重复**：测试类型表、样本覆盖表、11 项断言表、事实边界、两层日报结构在 2-4 处复制，H3 已是实际漂移实例。修复：收敛单一出处 + 其余引用。

**M2 · 判断字段档位无填法**：适配风险"正常↔谨慎推进"、阶段置信度高/中/低、跟进优先级四档均无判据。修复：每档补一句可判定判据。

**M3 · 无 CHANGELOG + 版本 stale**：无 CHANGELOG；openai.yaml display_name 仍"日报skill-v1.1-7.6"，与包名 v1.2 冲突。修复：加 CHANGELOG + 统一版本号。

**M4 · 缺料替代句式散落无统一句式库**：替代写法存在（比裸禁令好）但散落，无可照抄的缺料句式库；经济档模型最吃这刀。修复：新增 references/missing-data-phrases.md。

**L1 · skill 命名三处不一致**：daily-report-v1-2 / customer-chat-analyzer / 日报skill-v1.1-7.6 三名并存。修复：统一 canonical 名。

## 五、生产选型建议

quick 模式未跑真实模型，本节仅给结构性建议，量化分档待 full 模式补：
- **任何档模型上线前，先解 H1**：要么在宿主接好数据源连接器，要么把 skill 重新定位为"消费用户贴入资料包"。不解 H1，1-5 线在裸宿主里跑不起来。
- **经济档模型**建议外挂后置检查器：正则拦截价格量级词（几千|数万|几千到几万|万级）落在未标"待补充"的输出里，兜住 HF1/H3。
- **最安全运行形态**：单客户 / 逐客独立生成（短任务），避开批量长输出对经济档编造倾向的放大。

## 六、方法局限声明

- **非盲评、单遍静态审查**：quick 模式仅做文档级逻辑校验，未跑任何模型、无 Baseline 对比、无投票，结论对"模型实际行为"的预测是推断而非实测，噪声敏感。
- **向导全部为评估员保守替判**：作者不在场，8 题按保守方向替判，可能与作者真实意图有出入，需作者逐条复核后断言合同才定稿。
- **H1 的"降级可执行"判定**基于 example-input.md 的资料包格式确实存在；若目标宿主连"用户贴资料包"都不支持，则 1-5 线彻底不可执行。
- 严重度按"是否影响输出正确性/可执行性"判，非文档洁癖；H3 判 H 因其撞在最常跑的冒烟线 + 旗舰反编造场景。
