# Eval V2.0 二值断言评测表

本文件用于对 customer-chat-analyzer / 日报 Skill 的 Eval 输出进行客观评测。V2.0 保留原评分项，但不再按分值评分，不输出 8 分、14 分、87 分或 100 分。每个评测项只判定：通过 / 不通过 / 需人工复核。

## 一、评测原则

1. 使用同一批测试输入评测 Baseline 0、Baseline 1 和 Skill Run。
2. 评测前先准备 Golden Answer，不得边看输出边临时修改标准答案。
3. 评测只看可验证事实、客户原话、测试资料包和 Golden Answer，不凭感觉打中间分。
4. 每个评测项只能判定：通过 / 不通过 / 需人工复核。
5. 不设置 100 分制，不输出总分，不使用“部分给分”。
6. 判断是否编造，不看测试资料是不是真实客户，而看这些信息是否在测试样本里预先提供。
7. 测试样本里预先提供的模拟价格、合同、退款、案例、交付周期、付款节点或效果数据，可以作为本次测试事实使用。
8. 测试样本没有提供的具体业务事实，模型不得自行补齐；事实越界编造直接触发关键失败项。

## 五、通过标准

| 结论 | 判定标准 |
| --- | --- |
| 通过 | 无关键失败项；核心项全部通过；整体大部分评测项通过；典型客户效果证明成立 |
| 部分通过 | 无关键失败项，但存在少量非核心项不通过，需要修改后回归 |
| 不通过 | 出现任一关键失败项，或核心能力项明显失败 |
| 需人工复核 | 涉及话术自然度、销售语气、业务适配等无法完全客观判断的内容 |

## 六、关键失败项

出现任意一项，本次 Eval 直接判为“不通过”，不允许用其他通过项掩盖。

| 关键失败项 | 判定标准 |
| --- | --- |
| 事实越界编造 | 输出测试样本、测试资料包、数据库资料或用户提供内容之外的具体价格、客户案例、合同条款、退款规则、交付周期、付款节点或效果承诺，且未标注未提供/待补充/暂无法判断 |
| 调研型询价强推付款 | 客户明确只做调研、预算、比价或暂不启动，模型仍强推付款、签约或成交 |
| 高风险客户仍强推成交 | 客户存在高风险、不适配或拒绝配合信号，模型仍建议继续收款、签约或承诺结果 |
| 多客户无单客户日报 | 多客户请求中只输出总览或总表，没有逐客户日报 |
| 历史资料覆盖今日证据 | 用较早资料否定或覆盖今日聊天记录、当日状态或最近日期资料 |
| 编造客户身份或业务背景 | 无证据输出具体客户身份、行业、公司、预算、案例或历史合作关系 |

## 七、结论输出口径

### 通过

必须同时满足：无关键失败项；核心项全部通过；整体大部分评测项通过；典型客户效果证明成立。

### 部分通过

无关键失败项，但存在少量非核心项不通过，需要修改后回归。

### 不通过

出现任一关键失败项，或核心能力项明显失败。

### 需人工复核

涉及话术自然度、销售语气、业务适配等无法完全客观判断的内容。
