# Eval V2.0 Golden Answer 标准答案模板

本文件用于在评测前固定每个测试样本的标准答案，避免评测者根据模型输出临时改变评判口径。Golden Answer 不要求逐字匹配，但核心判断必须作为评测依据。

## 一、Golden Answer 使用规则

1. 每个测试样本必须先写 Golden Answer，再运行 Baseline 和 Skill Run。
2. Golden Answer 只写关键判断，不写完整日报。
3. 评测时允许不同表达，但不允许核心判断偏离。
4. 标准答案必须引用客户原话、测试资料包或聊天事实。
5. 阶段判断必须按客户已完成动作，不按热情程度。
6. 问价必须区分购买型、调研型、模糊询价。
7. 高风险客户必须写明禁止动作。
8. 如果证据不足，Golden Answer 必须写“证据不足”，不得强行设定唯一结论。
9. Golden Answer 必须明确已提供事实和未提供事实，作为事实边界评测依据。
10. 判断是否编造，不看测试资料是不是真实客户，而看这些信息是否在测试样本里预先提供。

## 六、示例 Golden Answer

```text
样本编号：eval_case_005_research_price
客户名称：钱总
样本类型：询价分级 / 调研型询价 / 预算收集

1. 正确阶段：A1
阶段依据：
- 客户仅表示做市场调研和预算收集。
- 未出现预约、购买、提交资料、签约、付款等已完成动作。

2. 推进信号：弱
推进信号依据：
- 客户问“大概多少钱”，但明确“今年不一定做”“不用约会，也不用催我付款”。
- 不应强收口付款，只能轻触达。

3. 询价类型：调研型询价
判断依据：
- 问价用于老板预算调研和供应商价格收集。
- 明确拒绝约会和催付款。

4. 主缺口：确认感；次缺口：安全感
判断依据：
- 客户需要价格区间、适用条件和预算判断标准。

5. 风险等级：谨慎推进
风险依据：
- 客户暂不启动，强推会引发反感。

6. 当日突出点方向：
- 客户是预算调研，不是购买型询价。

7. 下一步动作方向：
- 给价格区间、适用条件、判断标准和二次沟通节点，不催付款。

8. 建议回复必须做到：
- 接受客户当前只是调研。
- 给大概区间和适用条件。
- 不催约、不催付款。

9. 禁止动作：
- 不得判断为购买型询价。
- 不得强推付款。
- 不得编造具体价格，如果测试资料包未提供价格。

10. 事实边界：
- 若测试资料包未提供具体价格，只能写“价格区间需结合产品信息补充/待补充”，不得自行编造具体金额。
```
