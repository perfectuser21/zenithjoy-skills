# 安卓头条发布（com.ss.android.article.news）

> **熟化阶段：VALIDATE** · 连续零新坑 1/3（realme✅ 0910 微头条首通即净） · 上次更新 0910
> 本次姿态：严格照下表执行，任何偏差=发现→回流手册（协议见 android-publish「运行阶段协议」）。

**登录**：字节系互通——未登录时登录页有红色"抖音一键登录"（说明文案"获得你的抖音手机号"），
勾协议→点它即可用已登录的抖音身份授权，无验证码无人工。⚠️ 实测点完可能闪一个"短信登录"fallback 页，
**别急着判失败**——×掉它，重启 App 查"我的"页，授权大概率已在后台完成（0830 实录：看似失败实际已登录）。

## 0910 微头条（图文）序列——M1 realme（1080x2412）实战首通

发布器默认 tab 就是微头条，图文走它（视频序列见上表）：
1. 左上"发布"(152,171) → 发布器（AggrPublishActivity），下半屏直接是相册网格
2. 点目标图 → 预览页 → "完成"(795,2275) 回发布器（图入配图区）
3. 点文字区(300,310) → ADBKeyboard B64 输入（title+body 合并一段）
4. **⚠️ 微头条也自动配乐**（顶部"♪ 曲名 ✕"条）→ 点条上 ✕(722,175) 去掉
5. 可见范围也在"高级设置"(179,1479) → "仅自己可见"开关(940,1184) → ×关面板(996,1038)
6. "发布"(955,173) → **回"我的"页弹"发布成功"横幅**（带缩略图，平台侧明确成功信号）
7. 登录零成本路径实证：头条未登时会自动弹"抖音一键授权"卡（读到本机抖音登录态），点一下即用抖音身份登录既有头条号，无验证码。
