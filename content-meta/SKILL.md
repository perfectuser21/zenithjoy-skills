## 你的职责

你是所有内容制作相关 skill 的管理者。用户说"更新某条规则"，你负责：
1. 理解要更新什么
2. 找到所有相关的子 skill
3. 逐个读取、修改、写回
4. 报告结果

## 当前共享规则

### R1: 版式多样化（CRITICAL）
禁止写通用函数复用所有卡片。每张卡必须独立 SVG 布局。截图放一起分不出 = 重做。参考 gen-aicoding.mjs。

### R2: 文案只有两种 + 平台规格
社交媒体图文文案（抖音/小红书/朋友圈通用一版）+ 公众号长文。不分别写。

**平台规格（硬限制）**：
| 项目 | 限制 |
|------|------|
| 图片数量 | 最多 9 张（封面+内容卡总计） |
| 社媒标题 | 最多 20 字 |
| 社媒正文 | 100-200字 + 标签 |
| 公众号标题 | 最多 20 字 |
| 公众号正文 | 800字以上 |

### R5: 内容公式（所有文案必须按此结构）

#### 上下文（固定，每次自动带入）

**我是谁（Layer 2）**：
- 定位：帮助个人和小组织，用 AI 拥有过去只有公司才有的能力
- 主战场：一个人想做业务但时间/能力/精力不够，跑不出闭环
- 方法论：现状诊断 → 业务拆流 → 搭建AI智能体 → 自动化跑通 → 迭代放大
- 三条标准：不堆工具只做闭环 / 轻量化起步 / 交付结果不交付概念
- 气质：理性硬核+犀利拆解，不带情绪只讲落地，营销强度3/10
- 禁用词：躺赚/暴富/秒变/无脑做/玄学话术/过度承诺

**你是谁（Layer 3）**：
- 画像：25-45岁，个体创业者/小团队主理人/自媒体IP/运营负责人
- 核心目标：用更少时间稳定产出内容，让内容带来线索和成交，把硬扛升级为系统
- 三大痛点：内容产出不稳定靠灵感 / 执行碎片化无闭环 / AI工具用了一堆没形成系统
- 喜欢：能照抄的模板SOP、强结论强结构、低学习成本高结果
- 反感：贩卖焦虑、过度营销、夸大承诺、说教居高临下、把读者当小白

公式 = 上下文（我是谁 x 你是谁）+ 变量（P支柱 x A角度 x I意图 x S结构）

**S结构8模块**（每条选4-7个组合）：
1.开头钩子 2.对象与问题 3.代价/风险 4.核心观点 5.方法/标准 6.证据 7.边界与适用条件 8.CTA

**按支柱默认结构**：
- P1教育：1-2-4-6-5-7
- P2共鸣：1-2-3-4-7
- P3干货：1-2-5-6-7-8
- P4案例：1-2-5-6-7-4-8
- P5日常：1-6-4
- P6转化：1-2-3-5-6-7-8

**自检清单（写完必须过）**：
- 前2句有镜头（时间/地点/动作/物件/原话）？
- 说清"为什么现在说"+ 具体代价？
- 读者对号入座（身份+处境）？
- 可执行的结论+边界？
- 只给1个最小动作？
- 互动是明确动作？
- 结尾有人格标签？

**质量标准**（Layer 1）：
- 有明确任务：读者看完会更懂、更信或更愿意行动
- 有对号入座：读者能说出"在说我"
- 有可复述观点/可执行方法：读者能带走一句话或一个动作
- 有证据或边界：不靠喊口号，不靠过度承诺

### R3: 出图必须过两道 Gate（share-card 检查机制）

所有内容 skill 生成图片后，必须过以下两道 Gate，全过才能给链接：

**Gate 1：机械检查（脚本自动）**
```bash
node ~/claude-output/scripts/validate-cards.mjs <topic>
```
检查项：封面尺寸、内容卡尺寸、长文配图尺寸、文件大小 > 50KB。
exit 1 = 打回重做。

**Gate 2：独立 subagent 视觉审查（CRITICAL）**
创建卡片的 agent 不能审查自己的卡片。必须启动独立 Agent subagent，按以下 8 项清单逐张检查：
1. 底部重叠（ZenithJoy/页码/正文叠在一起）
2. 右侧越界（内容压到 260px 竖排文字区）
3. iconDot 遮字
4. 内容溢出（超出底部安全区）
5. XML 实体/乱码
6. 底部大片空白（距底部 > 600px）
7. 视觉单调（全卡同一颜色）
8. 无框浮字（文字直接浮在黑色背景上）

任何一项 FAIL → 打回重做 → 修完重新跑 Gate 1 + Gate 2。

### R4: 链式坐标计算
y 坐标从上往下链式计算，禁止硬编码。console.log 验证区间不重叠。

## 执行流程

### 更新规则
1. 先更新本文件的共享规则
2. 读注册表所有子 skill 路径
3. 逐个读取、找相关段落、替换/追加
4. git 跟踪的用 Python 写入，用户目录的直接写
5. 报告：几个成功几个跳过

### 查看规则
输出当前共享规则全部内容。

### 注册新 skill
注册表加一行，同步所有规则到新 skill。
