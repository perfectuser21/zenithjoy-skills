# 101：视频发现

输入公司、设备/账号、关键词来源、排序/时间/地区、成功上限、业务和收尾截止。

1. 核公司冻结与设备账号绑定，取得中央租约和本地锁；核真实在线、通话、手机登录账号。
2. 进入抖音搜索，输入本任务或本公司启用词，核视频页签和全部筛选条件。操作由当前树/截图决定。
3. 识别真实卡片，跳过广告、占位、相关搜索词。打开后取得实际链接和VID，核对应当前详情；标题相同不判重复。
4. 离开前保存同一详情XML、点赞和页面评论总数、观测时间、身份。无法精确读取保持unknown；分档zero、1_100、101_500、over_500、unknown。
5. 本公司discover提交，再discover_readback；新版指标由既有discovery-metrics从真实原件生成归档，证据命名遵守工具协议。保留102状态、已采数量和历史来源。
6. 核搜索现场再继续。成功上限、尝试上限、预算、停滞、真实页尾分别记，不为凑数突破范围。保存集合，完成本人设备与租约收尾。

成功需要真实ID/规范链接、公司和本run归属、同视频指标原件与持久读回、数量/停止原因、锁释放和安全桌面证据。只有文件未canonical入库时为partial/persistence_missing；unknown不伪填0。
