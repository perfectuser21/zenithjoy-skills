# Line 经营报告输出模板

严格按此结构输出（周报/月报把"今日/昨日"换成"本周/上周"、"本月/上月"）。

```markdown
# Line 经营日报 — 2026-07-12（周六）

## 总览

| Line | 完成任务 | 环比 | 决策 | PR 合并 | 进行中 |
|------|---------|------|------|--------|--------|
| Line 02 · 客户智能获客路径 | 3 | ▲+2 | 1 | 2 | 1 |
| Line 04 · 客户私域 AI 接管 | 1 | ▬持平 | 2* | 1 | 2 |
| Cecelia Harness Pipeline | 2 | ▼-1 | 0 | 2 | 3 |

（* 含语义推断归属；▲▼▬ 后跟与上一周期的差值）

全局：今日完成 6 个任务（昨日 5），新增 3 个决策（昨日 4），合并 5 个 PR。

## 分 Line 明细

### Line 02 · 客户智能获客路径（3 任务，比昨天多 2）
完成：
- 内容判定门槛客户端接线（PR #xxx 已合并）
- ……
决策：
- 抖音采集改手机录音+Whisper判定（硬归属）

### Line 04 · 客户私域 AI 接管（1 任务，持平）
……

**今日无产出**：Line 03 · GEO、Line 06 · 小龙虾

## 未归属（元数据卫生债）

- 任务「xxx」— 语义无法判断归属
- 决策「yyy」—（归属靠语义推断失败）

## 数据口径

完成 = completed_at 落在 2026-07-12 00:00–24:00（Asia/Shanghai）；决策 = created_at 在窗口内且 status=active；
PR = pr_merged_at 在窗口内。环比窗口 = 2026-07-11 全天。硬字段归属优先，标 * 的为语义推断。
```

写作纪律：
- 数字全部来自脚本 JSON + 语义归属结果，禁止拍脑袋补数。
- 明细里每条任务尽量带 PR 链接（task 详情的 pr_url）。
- 有 Line 环比大跌（完成数比上期少一半以上且上期 ≥2）时，在该 Line 小节末尾加一行"⚠ 产出下滑"提示，不做原因猜测——原因分析是 line-strategist / 主理人的事。
