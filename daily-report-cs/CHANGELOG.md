# daily-report-cs CHANGELOG

## v1.0.0 (2026-07-08)

从 daily-report v1.5.0 裁剪出的实时客服判断内核，首次注册。

- 保留判断规则：A1-A4 阶段、四感缺口、推进信号判档、询价分级、高风险识别、事实边界+资料缺失标准句式库
- 砍掉日报结构件：两层日报、本次分析资料范围模块、变更记录、文件输出规则、Eval 章节
- 输出格式改为单轮："一条可发送回复 + 内部判断标签 JSON"（stage/signal/inquiry/risk/gap/escalate）
- §6 询价分级新增"先判断是否出现价格/费用字眼，没有一律未询价"规则+判档速查表（修复实测中 inquiry 分类准确率从 47%→87% 的问题）
- §1 强化 JSON 标签输出为硬约束（修复实测中 20% 概率漏输出 JSON 的问题）
- §9 补充生产接入建议：JSON 缺失重试+安全默认值兜底、post_check.py 编造检测出口、模型选型结论

评测结论：gpt-5.4-mini，15 客户×3 遍复测，零编造(45/45)、高风险客户转人工 100% 稳定命中(15/15×3)、inquiry/stage/signal 多数投票准确率 87%/93%/87%，首响 p50≈2s、总时长 p50≈3.5s。测过 Claude Haiku 4.5 / Gemini 3.5 Flash / Gemini 3.1 Flash-Lite / DeepSeek v4-flash 均未跑赢；Haiku 4.5 在当前 prompt 封装方式下有系统性格式失败（60% 概率拒绝执行/输出元评论），暂不可用。
