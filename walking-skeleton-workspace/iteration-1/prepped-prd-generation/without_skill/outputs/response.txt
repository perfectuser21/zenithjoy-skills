### 6. 注意事项（风险提示）

1. **脚本未测警告**：`publish-kuaishou-image.cjs` 和 `publish-kuaishou-api.cjs` 都是"未测"状态，初次运行很可能有 bug，需要 systematic-debugging 支持
2. **API 方案优先**：推荐先跑 `publish-kuaishou-api.cjs`（Cookie+HTTP 直调，比 UI 自动化稳定）；如 API 端点 404，参照 SKILL.md 故障排查章节用 Chrome DevTools 抓包更新 URL
3. **会话 Cookie 可能过期**：快手 CP 的 `kuaishou.web.cp.api_st` / `kuaishou.web.cp.api_ph` 需要人工扫码续期；check-kuaishou-session 会提前检测
4. **CDP 端口复用**：19223 是快手专用端口，与抖音(19222)/小红书(19225) 互不冲突，但 Windows PC 重启后需 schtasks 重启浏览器
